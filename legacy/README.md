Frozen, superseded code from the project's first implementation: MLP baselines (`model.py`) and the grid/sphere/random-graph `World` factories, trained/analyzed against a rectangular grid world (`train.py`, `train_multitask.py`, `analysis.py`, `analysis_multitask.py`).

This was the first pipeline built before `manifolds/` existed and is kept for reference only — it is not actively developed. Active work (the `MultiTaskWorldModel` transformer, trained on `manifolds/` surfaces) lives in `src/`, `analysis/`, and `configs/`.
